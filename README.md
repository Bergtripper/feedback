# FEEDBACK

A DOTZERO research project: an observatory of AI capability, research automation and recursive progress.

## Foundation
FEEDBACK is an independent application repository but inherits the DOTZERO corporate visual foundation: semantic tokens, IBM Plex typography, editorial grid, light/dark modes and research-first information design.

## Research model
The public model is organized around four observables: C — research capability; K — loop closure; R — recursive gain; τ — generation time.

Evidence is explicitly typed as observation, estimate, hypothesis or scenario so interpretation is never presented as measurement.

## Roadmap
F0 foundation and data model → F1 The Loop → F2 evidence-backed indicators → F3 What If? → F4 evidence/methodology.
